# User Interface Design

## Visual direction

- Dark navy background.
- Bright blue highlights.
- Large rounded horizontal selection boxes.
- Minimal, clean presentation.
- Symbols are primary; text is secondary.

## Kid Mode game carousel

- One large selected game centered on screen.
- Neighboring games appear smaller and muted on either side.
- Neighboring games have no prominent text labels.
- Left and right controls browse games.
- Sound indicator in the upper-left.
- Battery indicator in the upper-right.

## Game actions

Large, stacked, full-width horizontal boxes.

Each box has one oversized symbol on the left and its label to the right.
The symbol must be visually dominant. Do not replace these with small square
cards or tiny icons.

Examples:

- Play or Resume: large play/continue symbol.
- Start Over: large circular restart symbol.

## Preview behavior

When available, static artwork is shown first. A muted gameplay preview may
replace it after approximately 2.5 seconds, using exactly the same display
area. Browsing to another game restarts the timer. Launching a game stops
preview playback immediately.

If no preview video exists, static artwork remains visible.
