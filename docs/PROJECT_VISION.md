# KiddOS Project Vision

## Purpose

KiddOS is a child-friendly gaming environment for the FunnyPlaying Retro
Pixel Pocket. It should let a young child pick up the device, turn it on,
choose a game, play, and return to the game selection screen without needing
an adult to explain the interface.

## Two experiences

### Kid Mode

A deliberately simple, visual, controller-only interface showing only games
approved by a parent.

### Adult Mode

The complete original handheld experience, including the existing EmuELEC
frontend and emulator environment wherever possible.

KiddOS should preserve rather than unnecessarily replace existing device
functionality.

## Design principles

- Simple enough for a preschool-aged child.
- Visual communication before written instructions.
- Large, clear selections.
- Predictable physical-button behavior.
- Parent authority over the child-facing library.
- Existing game files and saves are preserved when games are hidden.
- Offline operation for the core experience.
- Hardware-specific behavior must be tested, not assumed.

## Scope

The first target is the Retro Pixel Pocket. Other handhelds are outside the
initial implementation scope.
